# MEMORY MATCH - PWA Version

スマホ・PCで遊べる神経衰弱ゲームです。  
1人プレイだけでなく、CPU対戦や2〜4人でのローカル対戦にも対応しています。

## アプリを開く

PC・スマホのどちらからでも遊べます。

**公開URL**  
[https://memory-match-card-game.netlify.app/](https://memory-match-card-game.netlify.app/)

### QRコード

スマホで下のQRコードを読み取ると、すぐにゲームを開けます。

![MEMORY MATCH QRコード](/qr-code.png)

## 制作目的

誰でも簡単に遊べるゲームをテーマに、  
年齢や性別を問わず使いやすい、シンプルで見やすい神経衰弱ゲームを制作しました。

単純なカードゲームではなく、

- 1人プレイ
- CPU対戦
- 2〜4人プレイ
- 難易度選択
- スマホ対応
- PWA対応

などを追加し、Webサイトではなく
「スマホゲームアプリとして使えること」を意識して開発しました。

---
## プレイモード

- 1人プレイ
- CPU対戦
- 2人プレイ
- 3人プレイ
- 4人プレイ

2〜4人プレイは、1台のスマホを順番に使うローカル対戦です。

## 難易度

- EASY：16枚 / 8ペア
- NORMAL：24枚 / 12ペア
- HARD：32枚 / 16ペア

## 工夫した点

### 1. 誰でも使いやすいデザイン

特定の性別を意識した配色ではなく、
アイボリー・白・チャコール・落ち着いたグリーンを使用しました。

カードやボタンを大きくし、
スマホでも押しやすく、現在のプレイヤーやスコアが
分かりやすいUIを意識しています。

### 2. 複数のプレイ方法に対応

最初は1人用の神経衰弱として制作しましたが、
より多くの人が遊べるように、

- CPU対戦
- 2人対戦
- 3人対戦
- 4人対戦

を追加しました。

プレイヤーごとの得点管理や、
ターンの切り替え処理をJavaScriptで実装しています。

### 3. 難易度によるカード枚数の変更

難易度ごとにカード枚数を変更し、
ゲーム性に変化を持たせました。

EASYでは遊びやすさを重視し、
HARDではより記憶力が必要になる設計にしています。

### 4. スマホアプリとして利用可能

レスポンシブデザインに対応し、
スマホ画面を基準にUIを設計しました。

さらにWeb App ManifestとService Workerを使用し、
PWAとしてホーム画面に追加できるようにしています。

## 開発で学んだこと

この制作を通して、HTML・CSSによる画面設計だけでなく、
JavaScriptを使用したゲームロジックの実装を経験しました。

特に、

- 複数プレイヤーの状態管理
- ターン制御
- 条件分岐
- 配列操作
- DOM操作
- レスポンシブ対応
- PWA化
- GitHubとNetlifyを使用した公開

まで、Webアプリの制作から公開までの一連の流れを経験しました。

また、最初からすべての機能を実装するのではなく、
1人プレイの基本機能から制作を始め、
CPU対戦、2〜4人での複数人対戦、難易度選択などを
段階的に追加しました。

実際に動作を確認しながら機能やUIを改善していくことで、
小さく実装して検証し、改善を重ねる開発の進め方も学びました。

## スマホにアプリとして追加

### iPhone

1. Netlifyの公開URLをSafariで開く
2. 共有ボタンを押す
3. 「ホーム画面に追加」
4. 追加

### Android

1. Netlifyの公開URLをChromeで開く
2. メニューを開く
3. 「アプリをインストール」または「ホーム画面に追加」
4. 追加
